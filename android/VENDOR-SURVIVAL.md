# Выживание DSH в фоне: инструкции по вендорам (task-2)

Общее правило: системе мало разрешения — вендорные «оптимизаторы» режут фон
отдельно. После установки APK пройдите РАЗДЕЛ СВОЕГО вендора + проверку внизу.

## Xiaomi / Redmi / POCO (MIUI, HyperOS)

1. Настройки → Приложения → DSH → Автозапуск → **включить**.
2. Настройки → Приложения → DSH → Экономия батареи → **Без ограничений**.
3. Откройте шторку недавних, потяните карточку DSH вниз → замок
   («Закрепить»): MIUI не выгрузит процесс свайпом.
4. HyperOS: Настройки → Батарея → Дополнительные функции → DSH → разрешить
   фоновую работу.
5. В самом приложении: откройте экран «Работа в фоне» (баннер на главном
   экране) → «Разрешить работу без ограничений».

## Samsung (One UI)

1. Настройки → Батарея → Фоновые ограничения → «Никогда не спящие
   приложения» → **добавить DSH** (+).
2. Настройки → Приложения → DSH → Батарея → **Не ограничено**.
3. Настройки → Уход за устройством → Батарея → Адаптивная батарея → DSH
   не должен попадать в «спящие»; проверьте список «Глубокий сон» —
   DSH там быть НЕ должно.
4. Уведомление «DSH работает в фоне» не смахивайте и не глушите:
   его удаление на One UI 6+ может остановить ForegroundService.

## Huawei / Honor (EMUI, MagicOS)

1. Настройки → Приложения → DSH → Сведения о батарее → Автозапуск +
   Работа в фоне → **включить оба**.
2. Диспетчер телефона → Очистка/Ускорение → белый список → добавить DSH
   (иначе «оптимизация» при гашении экрана убьёт proot).

## OPPO / Realme / OnePlus (ColorOS, OxygenOS)

1. Настройки → Приложения → DSH → Использование батареи → Разрешить
   фоновую активность.
2. Недавние → меню карточки DSH → «Заблокировать» (замок).

## Vivo / iQOO (FuntouchOS)

1. Настройки → Батарея → Энергопотребление в фоне → DSH → разрешить.
2. iManager → Очистка → белый список → DSH.

## Проверка (все вендоры)

1. Откройте DSH, дождитесь интерфейса, погасите экран на 10 минут.
2. Разбудите: интерфейс должен отвечать БЕЗ сплэша «Запускаем DSH…».
3. Если сплэш появился — смотрите какой слой сработал:
   - уведомление сервиса пропало → вендор убил FGS: вернитесь к разделу
     вендора (автозапуск/замки/белые списки);
   - уведомление живо, но сплэш висит → умер proot/dsh web: экран
     Диагностика (task-8) → `dsh.out.log`, кнопка «Перезапустить» в уведомлении.
4. ADB-проверка (по желанию):
   `adb shell dumpsys deviceidle whitelist` — пакет `com.dsh.wrapper`
   должен быть в списке после battery-opt-out.

## Для разработчиков

- `adb shell cmd appops get com.dsh.wrapper RUN_IN_BACKGROUND` — должно быть `allow`.
- `adb shell dumpsys activity services com.dsh.wrapper` — виден `DshService`,
  `foreground=true`, тип `dataSync`.
- `adb shell dumpsys jobscheduler | grep dsh-keepalive` — запланированный
  периодический WorkManager-джоб.
